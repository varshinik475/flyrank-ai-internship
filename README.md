# Capstone Project

## Overview

This repository contains my capstone project, developed as part of my AI & Machine Learning coursework. The project demonstrates full-stack development practices, clean code organization, and AI-assisted software development using modern tools and workflows.

## Objectives

- Build a scalable full-stack application.
- Apply software engineering best practices.
- Use AI tools to improve development productivity.
- Maintain a clean Git history using Conventional Commits.
