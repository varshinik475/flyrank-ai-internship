# FlyRank AI Internship – AI Workflow Comparison

## Overview

This repository contains my submission for the FlyRank AI Frontend Engineering internship assignment. The objective is to demonstrate the difference between simply generating code with AI and using AI as an engineering partner through structured prompts, verification, testing, and code review.

The project implements a **Settings Form** with client-side validation and compares two AI-assisted development workflows.

## Features

* Settings form built with React
* Full Name, Email, Password, and Confirm Password fields
* Form validation
* Responsive user interface
* Accessibility improvements
* Automated testing (structured workflow)

## Branches

### `feature/vague-ai`

Implementation generated using a single, vague AI prompt with minimal guidance. This branch demonstrates the limitations of unstructured AI-assisted development.

### `feature/structured-ai`

Implementation created using a detailed specification, project constraints, accessibility requirements, verification steps, and automated tests. This branch demonstrates a structured AI engineering workflow.
